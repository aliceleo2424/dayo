## 2026-10-23 — 결제창 대신 무통장입금 안내 카드 (PortOne 미연동 기간)

주인(오너) 명시 요청. 카드 결제(PortOne)가 아직 연동되지 않아, 티켓 "결제하기" 이후 기존 "프리오픈 점검 중" 토스트 대신 **무통장입금 안내 카드**를 띄운다.

- 표시 조건: PortOne SDK 또는 고객사 식별코드가 없을 때만. 연동이 완료되면 코드 변경 없이 기존 결제창 흐름으로 돌아간다. admin 테스트 상품(`admin_test_1000`)은 기존 PRE-OPEN 안내 유지.
- 순서 유지: 연락처(이메일·휴대폰) 입력 → 환불 동의 → 안내 카드. 주문(`orders`) 행은 만들지 않는다(기존과 동일).
- 카드 내용: 선택 상품·금액 / 카카오뱅크 3333-3852-49984 여승현(88드래곤즈) / 계좌번호 복사 / 입금자명은 실명 / 입금 확인 후 영업일 기준 12시간 이내 충전 / `입금했어요 — DayO에 알리기`(hello@dayotalk.com으로 상품·금액·연락처가 채워진 메일) / 닫기(버튼·ESC·배경). KO/EN.
- 계좌 정보는 `ticket-payment.js`의 `BANK_TRANSFER` 상수 한 곳에서만 바꾼다. `window.DayOBankTransfer`로 노출(테스트·재사용용).
- 파일: `public/ticket-payment.js` (+ 루트 미러 `ticket-payment.js`), `tests/bank-transfer-notice-browser.cjs`(신규).
- 확인한 것: 실제 DOM 브라우저 테스트 KO/EN × 360/390/430/1280 — 계좌·금액·안내문·mailto 내용, 가로 넘침 없음, 버튼 탭 크기, 복사 폴백, 닫기 3경로, 페이지 에러 0. 운영 사이트에서의 실제 입금·메일 수신은 확인하지 않음.
- 남은 일: 입금 확인·티켓 충전은 Admin에서 수동(`admin_grant`). PortOne 연동 시 이 카드는 자동으로 사라지며, 그때 결제 알림(AI 오피스)도 붙인다.

## 2026-10-20 — 랜딩 맨 위(히어로)를 가로 전체 너비로

주인(오너) 요청. 맨 위 히어로가 둥근 박스 안에 들어가 있던 것(10/13 랜딩 분리 때부터)을 아래 이야기 카드·첫 대화 9,900원 구간처럼 화면 가로 전체로 펼침.
- 이미지·문구·버튼·색은 그대로. 둥근 모서리와 위아래 여백만 없앰. 글 시작 위치를 아래 두 구간과 같은 왼쪽 선(1080px 폭)에 맞춤.
- 버터색 그라데이션은 넓어진 폭에서도 글자 뒤에만 오도록 위치 계산을 바꿈. 넓은 화면(1051px 이상)에서는 높이를 540~640px로 조금 늘려 사진이 덜 잘리게 함.
- 모바일도 사진이 좌우 끝까지 닿게, 박스 모서리 없앰.
- 파일: `landing-views.css`, `landing-palette.css`, `index.html`(CSS 버전 번호만) — `public/` 동일 반영.
- 확인: 390 / 900 / 1440 / 1920px 화면에서 가로 스크롤 없음, 세 구간 글 시작선 일치.

## 2026-10-20 — 예약 알림용 휴대폰 번호 칸 (파트너 라운지 · 어드민)

주인(오너) 요청. 카카오 알림톡 연동 전 준비 — 파트너 11명 중 저장된 번호 0명이었음.
- 번호는 계정당 하나, 기존 `user_contact_info.mobile_phone`(결제 때 학습자가 넣는 칸)을 그대로 씀 → 어디서 넣든 다른 화면에 자동으로 같은 번호가 보임.
- 새 DB 함수 2개(본인 또는 관리자만): `dayo_contact_phone(uuid)`, `dayo_set_contact_phone(uuid,text)`. 010 11자리만 허용(+82 10… 자동 변환), 계정 이메일이 없으면 저장 불가. 마이그레이션 `122_contact_phone_shared.sql`, 운영 DB 적용 완료(2026-10-20).
- 파트너 라운지 프로필: 닉네임 아래 "예약 알림 받을 휴대폰 번호" + 자체 [저장] (기존 프로필 저장 버튼과 분리). `public/partner-contact-phone.js`, `public/partner.html` (+ 루트 미러).
- 어드민: 파트너 관리 표에 "알림 번호" 칸(바로 입력·저장), 회원 상세 > 기본 정보에 "휴대폰 (예약 알림)". `admin/src/components/admin/contact-phone-field.tsx`.
- 남은 일: 알림 업체 선택·카카오 채널 연결·템플릿 검수(주인), 이후 예약 확정/시작 1시간 전 알림 발송 연결.

## 2026-10-19 — 책장 + 벨기에 와플 이야기 데모 페이지 (/demo-story)

주인(오너) 요청. 보여주기용 별도 데모 링크 `https://www.dayotalk.com/demo-story`. 메뉴에 연결하지 않음, 검색 노출 막음(noindex), 로그인·저장·결제와 무관(새로고침하면 처음으로).
- 흐름: 나의 책장(나라별 책 4권, 벨기에만 열림) → 「즐거운 벨기에 여행 · 1장 와플 대작전」 → 완성 후 책장에 1장 + 내 한 줄 표시.
- 대답 고르기(정답 없음) → 고른 문장이 **섞인 단어 블록**으로 나오고 눌러서 순서대로 다시 맞춤. 다 놓았는데 순서가 틀리면 **자리가 틀린 단어만 분홍색으로 두 번 깜빡**이고 분홍색으로 남음 + 안내 문구. [다시 섞기] / [문장 보기]로 넘어갈 수 있음. 점수 없음.
- 이야기 문장(영·한)은 시안 제목 "와플 대작전"을 바탕으로 새로 씀. 기존 이야기 장면 형식(장면 소개 → 대답 2번 → 마무리 → 내 한 줄)과 같음.
- 파일: `public/demo-story.html` (+ 루트 미러 `demo-story.html`). 커밋 6139166, 73e54f0, 이번 분홍 깜빡임.
- 확인: 390px 헤드리스 브라우저로 처음부터 끝까지 클릭(오류 0), 운영 배포 READY.
- 남은 일: 실제 책장(마이페이지)에서 어디에 보여줄지, 나라별 책 구조로 바꿀지는 주인 결정 대기(`docs/DAYO_UX_IDEAS_LETTERBOX_BOOKSHELF.md` 6장).

## 2026-10-19 — 랜딩 스피킹 테스트 교체, 메일 디자인, 파트너 문구, 옛 로고 정리

배포: `main` d1bede3 (브랜치 4개 병합). 모두 주인(오너) 명시 요청.

### 1. 스피킹 감각 테스트 → "Emma 카톡" 대화 시뮬레이션 (영어 전용)
- 랜딩 `무료 스피킹 감각 테스트` 모달의 내용 교체. 한국 문화를 잘 아는 외국인 친구 Emma와 6턴 대화.
  - 매 턴 4개 답장 = 4가지 말버릇(유형). 가장 많이 고른 유형이 결과(동점이면 마지막 선택).
  - 유형(디저트): 마카롱=완벽주의 침묵형, 쿠키=단어 던지기형, 컵케이크=웃음 방패형, 푸딩=듣기만 프로형.
  - 매 턴 `한국어 찬스` 버튼(Emma가 한국어로 설명). 3번째 턴은 마이크로 말하기(브라우저 음성 인식, en-US).
    "I like"처럼 덜 끝난 답은 Emma가 되묻고 1회 재시도, 두 번째도 불명확하면 자연스럽게 넘어감. 건너뛰기 가능.
  - 결과 순서: 유형 카드 → Emma가 본 나 → 다음엔 이렇게 → `실제 대화에서 이렇게 말해보세요!`(표현 5개) → 가이드북 신청 → 대화 주제/예약 → 다시 하기.
- 언어 탭(불/일/중/스)은 숨김(영어 전용). 기존 말하기 3문장 코드는 남겨 두었고, 새 스크립트가 못 뜨면 예전 테스트가 대신 열림.
- 가이드북 신청 동의 UI: 맨 위 `아래 내용에 모두 동의합니다`(방문자가 직접 체크), 필수/선택 각각 체크박스 유지, 상세 설명은 화살표로 펼침. **광고 수신 동의는 기본 체크하지 않음**(KISA 안내서상 사전 체크 동의는 무효).
- 색: 세이지그린 #5F7D63 · 버터옐로우 #FFF4CC/#FFEAA7 · 아이보리 #FFFBF4 · 글자 #40362F.
- 파일: `public/emma-chat-test.js`, `public/emma-chat-test.css`, `public/index.html` (+ 루트 미러).
- 테스트: `tests/emma-chat-test-browser.cjs` (KO/EN × 360/390/430/1280, 마이크는 모의 음성인식).
- 로컬 기록: localStorage `dayo_speaking_sense_history`에 `format: 'emma-chat'`, `dessert_type`, `korean_help_used`, `mic_checked`.
